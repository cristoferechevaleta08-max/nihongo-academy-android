# Nihongo Academy

Reconstrucción Android nativa basada en el PDF `Nihongo_Academy_Ideas_App.pdf`.

- Kotlin + Jetpack Compose, interfaz en español, temas oscuro/claro.
- Catálogo de 15 idiomas y niveles JLPT N5–N1.
- Lecciones offline con ejercicios, corrección, aprobación mínima del 70% y registro de errores.
- Examen cronometrado por secciones, progreso local y plan de 12 semanas.
- Sobres diarios con tres cartas y colección persistente.
- Comunidad y sincronización requieren backend seguro; no se simulan.
- Voz mediante reconocedor Android; evaluación fonética especializada pendiente.

Requiere Android Studio, JDK 17 y Android SDK 35.
